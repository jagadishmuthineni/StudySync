# StudySync – Student Study Planner

StudySync is a web-based study planner designed to help students organize
their subjects, manage academic tasks, track deadlines, and monitor study progress.

## Features

- Student registration and login
- Add and delete subjects
- Create tasks with deadlines
- Mark tasks as completed
- View pending and completed tasks
- Track overall study progress
- View subject-wise progress
- Identify upcoming deadlines

## How to Run the Project

### 1. Start the Backend

Open a terminal:

cd backend

Activate the virtual environment and run:

python app.py

Backend runs at http://127.0.0.1:5000

### 2. Start the Frontend

Open another terminal:

cd frontend

Install dependencies if required:

npm install

Start the React application:

npm run dev

Frontend runs at http://localhost:5173

## Project Objective

The main objective of StudySync is to provide students with a simple
platform to manage academic activities, organize study tasks, and track
their progress in one place.
